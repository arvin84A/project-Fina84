# پروژه پایانی کاردانی کامپیوتر

## موضوع پروژه: پنل مدیریت ساده (Admin Panel)

این پروژه یک پنل مدیریت برای مدیریت کاربران و محتوا است.

### ساختار پروژه
- index.html: صفحه اصلی داشبورد
- style.css: طراحی ظاهری پروژه
- script.js: عملکردهای جاوا اسکریپت

### اطلاعات ورود
برای تست پروژه می‌توانید از اطلاعات زیر استفاده کنید:
- نام کاربری: admin
- رمز عبور: 123456

### نحوه اجرا
کافیست فایل index.html را در مرورگر (مثل کروم یا فایرفاکس) باز کنید.
